API Marketplace for LBG

A modern API Marketplace application designed for Lloyds Banking Group (LBG), built using React, Vite, JavaScript, Tailwind CSS, and Material UI for a fast, responsive, and elegant user experience.

🚀 Features

API Catalog: Browse and search APIs with advanced filters.
API Details: View documentation, endpoints, and usage guidelines.
Developer Dashboard: Manage subscriptions and monitor API usage.
Responsive UI: Built with Tailwind CSS and Material UI for a sleek design.
Fast Development: Powered by Vite for lightning-fast builds and HMR.


🛠 Tech Stack

React – Component-based UI
Vite – Next-gen frontend tooling
JavaScript (ESNext) – Modern syntax
Tailwind CSS – Utility-first styling
Material UI – Pre-built components for consistency
